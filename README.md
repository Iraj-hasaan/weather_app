# Weather App Using API 🌤️

A responsive weather application built using HTML, CSS, and JavaScript.

## Features

- Search weather by city name
- Display current temperature
- Display humidity
- Display weather condition
- Show weather icons based on weather conditions
- Handle incorrect city names
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- OpenWeather API

## How It Works

1. User enters a city name.
2. JavaScript sends a request to the weather API.
3. The API returns weather data in JSON format.
4. The application displays the temperature, humidity, weather condition, and icon.

## Concepts Learned

- Fetching data from APIs
- Handling JSON responses
- Using async/await
- Error handling
- Updating the DOM dynamically
- Working with API data

This project was created as part of an internship task to practice working with APIs and JavaScript.
